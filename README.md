## 使用方式

- 教師使用 sfyu@cdjh.ylc.edu.tw，可選學校 Google 教師身分登入，或沿用先前設定的系統密碼。
- 學生使用系統帳號，或限定派卷的個人辨識碼；沒有通用 PIN、示範密碼或內嵌正解。
- 建卷時匯入教用原卷並核對標準答案及配分。答案卷自動生成空白學用卷；題目卷需檢查去答案結果後再確認。
- 依班級或個人建立紙本／網頁任務，學生確認各格後交卷，以後端收件結果為準。
- 雙欄審卷提供存疑篩選、逐格核定與理由、PDF 紅筆批註保存、單份成績發布。明確發布後才排入通知。
- PDF 下載另有頁內預覽及列印；檔案選取或下載受限時可用 Chrome／Edge，JSON 建卷另可貼上內容。

## 資料與部署

新系統複製獨立資料庫，保留既有教師密碼、名冊、試卷與收件；原庫不受後續變更影響。新資料及原程式備份存於指定 Drive 根資料夾下的 20261102-新版網站系統。舊專案待寄通知不在新系統重送。

舊版免登入 POST 操作停用；新前端以 google.script.run 呼叫後端。伺服器驗證角色及作答範圍，判分不信任瀏覽器分數。金鑰僅在 GAS Script Properties，不放在 GitHub。

GitHub Pages 使用 main 的 /docs。config.js 定義後端，HTML 保留備援連結；協作平台嵌入可用完整分頁開啟。網址不傳送密碼或權杖。

執行 node check.mjs 可驗證相對路徑、角色轉址、嵌入替代連結、查詢字串清除及金鑰掃描。後端程式與私有移轉工具留在指定 GAS 專案及本機工作區，未隨入口公開。

AI 轉錄仍需核對；郵件服務接受不等於證明送達。實體手寫、真實信箱送達與各裝置下載相容性仍需實機驗證。
